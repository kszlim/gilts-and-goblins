# Gilts & Goblins

Defend your castle. Mind your interest rates.

[Play and download](https://kszlim.github.io/gilts-and-goblins/)

This public repository hosts the website and compiled nightly releases.
The game source is maintained in a separate private repository.
[Download the latest nightly](https://github.com/kszlim/gilts-and-goblins/releases/latest)
for Windows x86_64, macOS Apple silicon, Linux AppImage, or Android ARM64.
The website also hosts the browser game. Build metadata and SHA-256 checksums
accompany each release. Nightlies are development previews.
